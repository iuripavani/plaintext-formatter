# Changelog

## 0.1.0

- Native Plain Text Format Document and Format Selection, including unsaved tabs.
- Conservative parser-backed JSON, XML, YAML, SQL, JavaScript/TypeScript and CSS detection; bounded HTML/Python support.
- Provider-first formatting through hidden language-specific documents, with validated JSON/XML/YAML/SQL fallbacks.
- Region detection, protected Markdown fences, overlap resolution, and one-batch code-block formatting.
- Syntax/content validation, cancellation and stale-source protection, bounded document/region analysis.
- Local milestone counter with 10-operation eligibility, two-day prompt cooldown, and 30-day click cooldown.
- Unit tests, real VS Code integration tests, CI, contributor documentation, and VSIX packaging.
